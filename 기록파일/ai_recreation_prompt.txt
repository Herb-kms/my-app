# 3D 재활용 공장 시뮬레이터 & 샌드박스 빌더 프로젝트 명세서 (AI 복원용 완벽 가이드)

이 문서는 React, React Three Fiber (R3F), @react-three/drei 기반으로 개발된 3D 게임 프로젝트의 모든 로직, 파일 구조, 컴포넌트 세부 디자인(색상, 좌표, 재질 포함)을 다른 AI가 100% 동일하게 재현할 수 있도록 극도로 상세하게 작성된 프롬프트입니다. 외부 GLTF 에셋 없이 오직 R3F의 기본 도형(Box, Cylinder, Sphere) 코드만으로 하드코딩하여 투박한 산업용 중장비 느낌을 내는 것이 핵심입니다.

---

## 1. 파일 구조 및 핵심 로직
- `src/constants/gameConstants.js`:
  - `MACHINE_CONFIGS`: 5가지 기계 타입 정의 (id, type: 'SORTING', 'CRUSHING', 'CLEANING', 'DRYING', 'PACKAGING', price, processTime).
  - `BELT_POINTS`: 그리드 사이즈(2.5 단위) 기준 컨베이어 벨트 경로.
- `src/App.jsx`:
  - 상태 관리: `placedBelts`, `placedMachines`, `movingItems`, `money`, `isBuilderMode` (Zustand 또는 React State 사용).
  - 초기화: 게임 시작 시 7개의 벨트(일자형)와 5종류의 기계를 기본 좌표(Z축 간격 2.5)에 자동 배치 (DEFAULT_MACHINES, DEFAULT_BELTS).
  - 게임 루프 (`useFrame`): `movingItems` 배열을 순회하며 벨트 경로를 따라 이동(속도: 1.5 ~ 2.0).
  - 충돌/가공 로직: 아이템의 Z좌표가 기계의 Z좌표와 오차범위(0.1) 내에 있고, 아이템의 단계(stage)가 기계 타입과 일치하면 이동을 멈추고 `PROCESSING` 상태가 됨. 기계의 `processTime`에 따라 progress(0~100) 증가. 100이 되면 다음 단계로 진화하고 다시 이동. 5단계 완료 시 매각되어 money 증가.
  - 카메라: `OrbitControls` 사용 (enablePan=false). 
- `src/components/3D/BuilderComponents.jsx`:
  - 마인크래프트 스타일 하단 인벤토리(UI) 제공 (숫자 1~6키로 빌드 아이템 선택).
  - 3D 커서(Reticle): 마우스 Raycaster가 바닥(Y=0)과 교차하는 지점을 계산. `Math.round(val / 2.5) * 2.5` 공식을 적용해 정확히 2.5 단위 그리드에 스냅되도록 반투명 고스트 블록 렌더링.
  - 클릭 시 해당 위치에 블록/기계 설치, 우클릭 시 삭제. 중복 설치 방지 로직 포함.

## 2. 3D 디자인 가이드라인 (핵심: 산업용 투박함)
모든 기계와 컴포넌트는 `MachineComponents.jsx`에 작성됩니다. 매끄러운 SF 스타일이 아닌, 철판이 두껍고 각진 실제 공장 기계처럼 모델링해야 합니다. 
- 재질: `meshStandardMaterial`을 사용하며, 철재 느낌을 위해 `metalness={0.4~0.8}`, `roughness={0.5~0.8}` 값을 적극 활용합니다.
- 조명/네온: 활성화(isActive) 상태일 때 빛나는 이펙트는 `emissive` 속성과 `emissiveIntensity={1~2}`를 사용합니다.

### 2-1. 공통 유틸리티 컴포넌트
1. **WarningStripes (경고 빗금무늬)**:
   - 기계 하단에 부착. `Box args={[0.2, 0.15, 0.05]}` 블록을 for문으로 나열. 짝수/홀수 인덱스에 따라 색상(빨간/흰색 또는 노란/검은색)을 교차 배색.
2. **ControlPanel (측면 조작 콘솔)**:
   - 본체 측면에 부착. 수직 스탠드(`Box [0.6, 0.8, 0.6]`) 위에 비스듬하게(`rotation={[-Math.PI/6, 0, 0]}`) 깎인 콘솔(`Box [0.7, 0.5, 0.1]`) 배치.
   - 콘솔 윗면에 검은색 스크린(emissive="#002200")과 빨강/초록 버튼 2개(`Box [0.08, 0.08, 0.05]`) 부착.

### 2-2. 기계 좌측 모니터 암 UI (상태 표시 전광판) ★매우 중요★
모든 기계는 공중에 떠있는 UI를 쓰지 않고, 왼쪽 면에 단단하게 볼트로 고정된 물리적인 전광판을 가집니다.
- 위치/각도: `group position={[-1.9, 1.8, 0.6]} rotation={[0, Math.PI / 12, 0]} scale={0.5}` (기계 본체와 클리핑되지 않게 -1.9로 빼고, 플레이어를 향해 15도 틈)
- 모니터 암 뼈대: 기계 왼쪽 면과 전광판을 잇는 두꺼운 쇠기둥 `Box args={[1.6, 0.2, 0.2]} position={[0.8, 0, -0.1]}`. 꺾이는 부분에 관절 장식 `Cylinder args={[0.2, 0.2, 0.3]}`.
- 전광판 프레임: `Box args={[2.2, 1.2, 0.2]}` (색상: #222)
- 하단 게이지 바: 검은색 배경 홈(`Box [1.8, 0.2, 0.05]`) 위에 progress 변수에 비례해 가로가 늘어나는 청록색 네온 바(`Box args={[1.7 * (progress/100), 0.1, 0.06]}`, `emissive="#00ffcc"`).
- 아날로그 계기판(좌측): `circleGeometry args={[0.22]}` 배경. 테두리 장식 눈금으로 `ringGeometry args={[0.16, 0.2, 16, 1, 0, Math.PI]}`(반원). progress 값에 따라 회전하는 붉은 바늘 `group rotation={[0, 0, Math.PI - (progress/100)*Math.PI]}`.
- 우측 상단 상태등: isActive 상태일 때 밝은 초록색(emissive)으로 빛나는 작은 Box.
- 텍스트: @react-three/drei의 `<Text>` 사용. 기계 이름 출력.

## 3. 개별 기계 특화 모델링 (크기는 대략 가로 2.6, 세로 3.1 꽉 채움)
1. **SORTING (분류기)**: 
   - 메인 색상: 파란색 (`#1f57a3`).
   - 형태: 양 옆에 두꺼운 벽(`Box [0.5, 1.8, 3.0]`) and 상단 덮개(`Box [2.4, 0.8, 3.0]`)가 있는 터널 형태. 컨베이어 벨트 입구/출구에 가림막.
   - 이펙트: isActive 시 터널 내부에 반투명 네온 청록색 스캐너 바닥(`Box [1.8, 0.1, 1.8]`) 발광.
2. **CRUSHING (파쇄기)**:
   - 메인 색상: 노란색 (`#d9a521`).
   - 형태: 위아래가 묵직하고 전후면이 비스듬하게 깎인 장갑차 뚜껑 같은 커버(`rotation={[Math.PI/6, 0, 0]}`).
   - 애니메이션: 중앙에 파쇄기 프레스 블록(어두운 회색 `Box [1.0, 0.8, 1.0]`)이 있고, `useFrame` 내부에서 `Math.sin(state.clock.elapsedTime * 8)`을 이용해 Y축으로 쾅쾅 찍어내리는 상하 왕복 운동 구현.
3. **CLEANING (세척기)**:
   - 메인 색상: 짙은 녹색 (`#2e7d32`).
   - 형태: 세로로 높은 벽. 지붕 위치(Y=2.9)에 거대한 사각형 물탱크 얹음. 측면 벽에는 세로로 긴 은색 실린더 배관 장식 추가.
   - 이펙트: isActive 시 터널 중앙에 파란색 반투명 큐브(`emissive="#00aaff", opacity=0.3`)가 나타나 물보라를 표현.
4. **DRYING (건조기)**:
   - 메인 색상: 바디는 진회색 (`#444`), 지붕은 오렌지색 (`#d84315`).
   - 형태: 철갑 바디 형태에 천장에 거대한 오렌지색 히터 팩 탑재.
   - 이펙트: 내부에 검은색 발열판이 있고, isActive 시 그 위에 붉게 빛나는 네온 박스(`emissive="#ff3300", opacity=0.8`)가 겹쳐지며 뜨겁게 달아오르는 연출.
5. **PACKAGING (포장기)**:
   - 메인 색상: 벽면은 흰색/연회색 (`#e0e0e0`), 지붕 프레임은 녹색 (`#2e7d32`).
   - 형태: 상단 전면부 허공(Y=2.3, Z=1.0)에 Z축 기준으로 누워있는 두꺼운 갈색 실린더(`rotation={[0,0,Math.PI/2]}`, 거대한 크라프트 종이 롤)가 장착됨.

## 4. 컨베이어 벨트 (ConveyorBelt 컴포넌트)
- 바닥 그리드(2.5)를 빈틈없이 꽉 채우기 위해 실제 벨트 표면 크기를 `Box args={[2.45, 0.08, 2.45]}`로 크게 잡음. 색상은 무광 검정.
- 벨트 테두리를 감싸는 더 큰 짙은 회색 금속 프레임 `Box args={[2.5, 0.12, 2.5]}`을 살짝 아래(Y=-0.02)에 배치하여 입체감 부여.
- 벨트 표면 위 중앙에는 진행 방향(+Z)을 가리키는 청록색 빛나는 화살표(긴 Box 1개와 비스듬한 짧은 Box 1개 조합) 장식 배치.
