========================================================================
[3D 재활용 시뮬레이터] 지금까지 진행된 작업 기록 요약
========================================================================

본 파일은 프로젝트 배포 준비 및 빌드 오류 수정 과정과 지금까지 작성된 작업 명세서를 정리한 기록 파일입니다.

------------------------------------------------------------------------
■ 1. 깃허브 및 Vercel 배포 진행 상황
------------------------------------------------------------------------
- 프로젝트를 깃허브 원격 저장소(https://github.com/Herb-kms/my-app.git)에 업로드하고 Vercel로 호스팅하기 위한 설정 준비 완료.
- 로컬 환경(Windows)에서 빌드(`npm run build`)가 소리 없이 비정상 종료(exit 1)되는 현상의 원인 규명:
  * 원인: Node.js v24 버전과 Windows OS 한글 폴더명("웹페이지", "웹프(REACT)", "프로젝트(재활용3D시뮬레이션)") 간의 파일 삭제(`fs.rmSync`) 관련 알려진 버그 충돌.
  * 해결/안내: Vercel 배포 서버는 영문 폴더 경로(리눅스 환경)와 안정적인 Node LTS 버전(18 또는 20)을 기본으로 사용하므로, 로컬의 이 한글 경로 충돌 버그에 영향을 받지 않고 정상 빌드됩니다.

------------------------------------------------------------------------
■ 2. Vercel 빌드 오류(ESLint Warnings) 해결 사항
------------------------------------------------------------------------
Vercel 빌드 시 컴파일 경고가 에러로 인식되어 빌드가 끊기던 모든 세부 항목들을 로컬 코드에서 완벽히 수정 완료했습니다:

① ItemComponents.jsx (연산자 우선순위 경고 해결)
   - 기존: dist < 4.0 !== isNear (비교 연산자와 일치 연산자 혼용)
   - 수정: (dist < 4.0) !== isNear (괄호 처리로 모호함 제거)

② PlayerComponents.jsx (미사용 변수 제거)
   - 기존: const { camera, gl } = useThree(); 및 frontVector, sideVector 미사용
   - 수정: gl 및 frontVector, sideVector 선언부 모두 코드에서 완벽히 제거 완료

③ BuilderComponents.jsx (미사용 변수 제거)
   - 기존: const isMachine = ['SORTING', 'CRUSHING', 'CLEANING', 'DRYING', 'PACKAGING', 'SHIPPING_BIN'].includes(itemType);
   - 수정: 사용하지 않는 isMachine 변수 선언부를 코드에서 완전히 제거 완료

④ useFactorySimulation.js (React Hook 의존성 배열 누락 해결)
   - 기존: useEffect 내부에서 playerPositionRef를 참조하지만 의존성 배열에 누락됨
   - 수정: 의존성 배열(dependency array) 끝에 playerPositionRef를 올바르게 명시

⑤ UIComponents.jsx & constants.js (미사용 변수/임포트 제거)
   - 기존: 사용하지 않는 useState, THREE 라이브러리가 임포트되어 있음
   - 수정: 로컬 최신 파일에서 해당 미사용 임포트를 완전히 지워 경고를 제거함 (원격 브랜치에 코드가 올라가면 자동 반영)

⑥ GameScene.jsx (미사용 임포트 제거)
   - 기존: Sky가 임포트되었으나 사용되지 않음
   - 수정: import 구문에서 Sky 제거 완료

⑦ MachineComponents.jsx (미사용 컴포넌트 제거)
   - 기존: RoboticArm 컴포넌트가 정의되어 있으나 사용되지 않음
   - 수정: 미사용 RoboticArm 함수 코드 전체 제거 완료

⑧ IntroTutorial.jsx (React Hook 의존성 배열 누락 해결)
   - 기존: useEffect 내부에서 slide.description을 사용하나 의존성 배열에 누락됨
   - 수정: 의존성 배열에 slide.description 추가 완료

⑨ audioManager.js (미사용 변수 제거)
   - 기존: py 변수가 구조 분해 할당으로 선언되었으나 사용되지 않음
   - 수정: py 변수를 할당에서 생략하고 [px, , pz] 형태로 수정 완료
