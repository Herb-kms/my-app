[React 프로젝트 GitHub 연동 및 Vercel 배포 방법]

이 가이드는 현재 작성된 리액트 프로젝트를 GitHub에 업로드하고, Vercel을 통해 웹사이트로 배포(유포)하는 과정을 설명합니다.

======================================================================
1. 배포가 가능한가요?
======================================================================
네, 당연히 가능합니다! 
파일 확장자(.js 및 .jsx 혼용)는 Vercel 배포에 아무런 영향을 주지 않습니다. Vercel 서버에서 프로젝트를 빌드할 때 모든 파일을 컴파일러가 알아서 합치고 변환해 주기 때문입니다.

======================================================================
2. GitHub에 프로젝트 올리기 (최초 1회)
======================================================================
① GitHub(https://github.com)에 로그인한 뒤, 우측 상단의 [+] -> [New repository]를 클릭합니다.
② Repository name을 입력하고 (예: recycling-3d-simulation), 다른 설정은 건드리지 않은 채 [Create repository]를 누릅니다.
③ VS Code 터미널(또는 CMD)을 열고 아래 명령어를 순서대로 입력합니다.

  # 1. 깃 저장소 초기화 (이미 되어있다면 생략 가능)
  git init

  # 2. 업로드할 파일들을 장바구니에 담기 (.gitignore에 등록된 node_modules 등은 제외됨)
  git add .

  # 3. 버전 기록 생성
  git commit -m "Deploy React 3D Simulation"

  # 4. 기본 브랜치 이름을 main으로 변경
  git branch -M main

  # 5. 내 로컬 폴더와 GitHub 저장소 연결 (GitHub 페이지에 적힌 주소를 넣으세요)
  git remote add origin https://github.com/본인계정이름/레포지토리이름.git

  # 6. GitHub 저장소로 코드 전송
  git push -u origin main

======================================================================
3. Vercel로 웹사이트 배포하기
======================================================================
① Vercel 홈페이지(https://vercel.com)에 접속하여 회원가입/로그인합니다. (이때 "Sign Up with GitHub"을 추천합니다.)
② 로그인 후 대시보드 화면에서 우측 상단의 [Add New...] 버튼을 누르고 [Project]를 클릭합니다.
③ 연동된 GitHub 계정의 저장소 목록이 나타납니다. 방금 만든 레포지토리 옆의 [Import] 버튼을 누릅니다.
④ Configure Project 화면이 나오면 아래 내용을 확인합니다:
   - Framework Preset: "Create React App" (자동 인식됨)
   - Root Directory: ./ (기본값)
⑤ 하단의 [Deploy] 버튼을 누릅니다.
⑥ 약 1~2분 후 빌드가 완료되며 폭죽 효과와 함께 웹사이트가 생성됩니다! 화면에 표시되는 도메인 주소(예: https://...vercel.app)를 클릭하여 접속해 보세요.

======================================================================
4. ⚠️ 배포 시 가장 자주 발생하는 에러 및 대처법
======================================================================
■ 대소문자 불일치 에러 (가장 중요)
  - Windows 컴퓨터에서는 파일 이름의 대소문자가 달라도 import가 작동합니다.
  - 하지만 Vercel의 서버 환경(Linux)은 대소문자를 매우 엄격하게 구별합니다.
  - 예: 실제 파일명이 'BuilderComponents.jsx'인데, 코드 내에서 'import ... from "./Buildercomponents"'처럼 불러온 부분이 있다면, 로컬에서는 작동해도 Vercel 배포 시 컴파일 에러가 발생합니다. 배포 전 대소문자 매칭을 꼭 검토해 주세요.

■ 소스 코드 수정 후 재배포 방법
  - 한 번 Vercel과 GitHub을 연동해 두면, 코드 수정 후 터미널에 아래 명령어만 치면 끝납니다.
  - Vercel이 수정을 감지하여 웹사이트를 자동으로 재빌드/업데이트해 줍니다.
    * git add .
    * git commit -m "수정사항 입력"
    * git push origin main
