[JS와 JSX의 차이점 및 사용 이유 정리]

안녕하세요! 리액트(React) 개발 시 .js 파일과 .jsx 파일의 차이점, 그리고 왜 .jsx를 사용하는지 정리해 드립니다.

======================================================================
1. 핵심 요약: .js 파일로 만들어도 되나요?
======================================================================
결론부터 말씀드리면, "이 프로젝트(Create React App 기반)에서는 .js 파일로 만들어도 정상적으로 동작합니다." 
하지만 아래의 이유들 때문에 React 컴포넌트는 .jsx 확장자를 사용하는 것이 업계 표준이자 권장 사항입니다.

======================================================================
2. JS와 JSX는 어떻게 다른가요?
======================================================================
■ JS (.js) - JavaScript
  - 표준 자바스크립트 문법만을 담는 파일입니다.
  - HTML 태그처럼 생긴 문법(<App />, <div> 등)은 원래 자바스크립트 표준 문법이 아닙니다.

■ JSX (.jsx) - JavaScript XML
  - 자바스크립트 파일 안에서 HTML과 유사한 마크업 문법을 직접 작성할 수 있게 해주는 '확장 문법'입니다.
  - 브라우저는 JSX 문법을 직접 읽지 못하므로, 빌드 도구(Babel 등)가 이를 일반 자바스크립트 함수 호출 코드(React.createElement...)로 변환(트랜스파일)해 줍니다.

======================================================================
3. .jsx 확장자를 사용하는 이유와 장점
======================================================================
① 명확한 역할 분리 (가시성)
  - 확장자만 보고도 이 파일이 "UI 화면을 그리는 React 컴포넌트(.jsx)"인지, 아니면 "단순 데이터나 비즈니스 로직만 담긴 순수 자바스크립트 파일(.js)"인지 쉽게 파악할 수 있습니다.
  - 예시 (현재 프로젝트 구성):
    * 컴포넌트: PlayerComponents.jsx, BuilderComponents.jsx (.jsx 사용)
    * 로직/설정: constants.js, audioManager.js (.js 사용)

② 개발 도구(IDE)의 자동 지원 및 에디터 편의성
  - VS Code 등 대부분의 에디터는 파일 확장자가 .jsx일 때 React 자동 완성, HTML 태그 자동 완성(Emmet), 구문 강조(Syntax Highlighting) 및 코드 포맷팅을 훨씬 더 정확하게 지원합니다.

③ 현대적인 빌드 도구와의 호환성 (Vite 등)
  - 현재 프로젝트는 Webpack/Babel을 사용하는 react-scripts(CRA) 환경이라 .js 파일 내부의 JSX도 자동으로 변환해 줍니다.
  - 하지만 최근 매우 대중적으로 쓰이는 최신 빌드 도구인 Vite나 Esbuild 등은 성능 최적화를 위해 매우 엄격한 규칙을 적용합니다. 이러한 도구들은 ".js 파일 내부에는 JSX 문법이 없다"고 가정하고 빠르게 처리하기 때문에, .js 파일에 JSX 문법을 쓰면 컴파일 에러를 발생시킵니다.
  - 따라서 나중에 프로젝트를 Vite 등으로 마이그레이션하거나 다른 최신 프레임워크를 사용할 때 호환성을 유지하기 위해서라도 처음부터 .jsx를 쓰는 것이 안전합니다.

======================================================================
결론 및 권장 규칙
======================================================================
- UI 레이아웃과 HTML 태그(<...>)가 들어가는 리액트 컴포넌트 파일: .jsx 사용 권장
- 순수 자바스크립트 함수, 설정 값(constants), API 호출 로직 등 UI가 없는 파일: .js 사용 권장
